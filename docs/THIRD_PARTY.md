RobotExpressive's upstream license and modification notes are preserved in [RobotExpressive-README.md](../client/assets/licenses/RobotExpressive-README.md). VitruvianGodot's asset provenance and its distinction between CC0 character assets and MIT project code are preserved in [VitruvianGodot-NOTICE.md](../client/assets/licenses/VitruvianGodot-NOTICE.md). ambientCG's license explicitly covers redistribution of raw asset files in a game: [published license](https://docs.ambientcg.com/license/).

[Download checksums and source URLs](../client/assets/sources.json) record the downloaded GLBs and texture archives. The downloaded source models themselves are unmodified.

The arena geometry, game logic, shell shaders, mesh-particle effects, and UI were authored for this project. No third-party effect package or code library is required. Godot is the game engine and is not bundled by this source project.

## Flow State animation sources - September 21, 2026

- **Quaternius / Tomas Laulhe:** [Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html) and [Universal Animation Library 2](https://quaternius.com/packs/universalanimationlibrary2.html), free Standard editions, CC0 1.0. Library 1 came from the creator's [OpenGameArt upload](https://opengameart.org/content/universal-animation-library); Library 2 came from the creator's free itch.io download. Original GLBs are in `client/assets/animations/source/quaternius_standard*.glb`; original notices are in `client/assets/licenses/Quaternius-UAL*.txt`. Retargeted clips provide jab, cross, hook, guard entry, locomotion, roll, hit reactions, knockback, and get-up.
- **Carnegie Mellon University Graphics Lab:** [motion capture database](https://mocap.cs.cmu.edu/), subject 87 takes 01 and 03 (jumping spin kick and backflip), subject 135 takes 02, 04, 07, 09 and 11 (Shotokan karate strikes/slips, front kick, roundhouse, stepping strike and side kick), and subject 14 take 01 (boxing stance and turning strike). ASF/AMC source files are bundled in `client/assets/animations/source/`. The database permits use in commercial products but prohibits selling the motion data itself, including converted data. These files are included as source assets for this game, not as a standalone animation product. A local usage notice is in `client/assets/licenses/CMU-MOCAP-NOTICE.md`.
- Attribution: CMU Graphics Lab captured these motions; its database was supported by NSF EIA-0196217. Source: mocap.cs.cmu.edu.

`client/tools/bake_combat_library.gd` maps the source rigs to the existing human, samples and trims the clips, retains captured vertical motion, and stores planar root travel as clip metadata so CharacterBody3D collision can apply the captured movement. The baked runtime resource is `client/assets/animations/kung_fu_library.res`. Downloaded-file hashes are recorded in `client/assets/sources.json`. The impact/whoosh audio is generated locally by project code.

The connected-combat revamp adds project-authored strike arcs, inverse-kinematics constraints, pose blends, locomotion layers, and paired knee/sweep sequences on these source motions. The active game does not use the retained backflip or aerial spin clips, library-2 hook, or physical ragdolls. No Sleeping Dogs assets or code are included.

The full-body motion pass adds six trimmed boxing clips from the already bundled CMU 14_01 take. Eleven active attack entries preserve the captured body rotations; some share a source performance. Side-kick orientation is corrected on the entire body. No new third-party files were downloaded for that change.

The grounding correction uses consecutive frames 584-623 for the jab-to-cross cut with one heading; cross continues through frame 688. The active guard uses frames 480-520. Planar travel is reconstructed from the retargeted supporting foot to account for different body proportions; original root samples remain in metadata for diagnostics. Front and round kicks also receive whole-body heading correction. Hit clips supply additive recoil relative to their neutral end poses. These are local processing changes to the existing assets; no new assets or licenses were added.

The September 24 motion pass adds subject 135 take 02, trimmed into a raised-knee straight and two defensive slips, and recuts the existing take 09 into a stepping karate straight. The bake stores the striking limb position at contact for target approach calculations. The SHA-256 of the new AMC is recorded in `client/assets/sources.json`.
